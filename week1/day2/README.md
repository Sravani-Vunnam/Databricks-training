# Databricks Training – Day 11

This repository contains the SQL practice queries completed during Day 11 of the Databricks Training program provided through our college.

The exercises focus on learning and practicing SQL concepts using sample Employee, Department, and Project tables.

---

# Topics Covered

## Basic SQL Queries
- SELECT statements
- Filtering using WHERE clause
- Selecting specific columns

## Pattern Matching
- LIKE operator
- Wildcards (`%`, `_`)

## Date Functions
- YEAR()
- MONTH()
- Date filtering

## Aggregate Functions
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()

## GROUP BY and HAVING
- Department-wise analysis
- Aggregate filtering

## Sorting Data
- ORDER BY clause
- Ascending and descending sorting

## Joins
- INNER JOIN
- LEFT JOIN

## Subqueries
- Nested queries
- Correlated subqueries
- Highest and second highest salary queries
